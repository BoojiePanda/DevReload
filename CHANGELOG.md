# Changelog

## 1.1.0 - September 25, 2026

- Gave DevReload a crisp black-and-pink **DR** icon in the AddOns list, settings, and minimap.
- Added proper LibDataBroker and LibDBIcon support, so WindTools can collect the minimap button into its button bar.
- Added a setting to show or hide the minimap button.
- Restyled the on-screen Reload UI button with the Boojie black background, pink border, pink lettering, and matching close button.
- The transparent pink hover effect was not intentional, but it looked too good to remove, so it is staying.
- Added the current version beside the addon title in Blizzard's AddOns settings.
- Preserved the saved reload-button position, size, and per-character visibility.
